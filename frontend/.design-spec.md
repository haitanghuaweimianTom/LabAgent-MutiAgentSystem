# 设计规范（基准：frontend/src/app/components/PdfManager.tsx）

目标：把目标页面改造成和 PDF 管理页一致的设计语言：**居中卡片 + data-design-id 打标 + 统一按钮 + 居中表单内容**。
**绝对保留所有功能逻辑**——只改 className / 加包裹 div / 加 data-design-id 属性。

## 必读
先 Read `frontend/src/app/components/PdfManager.tsx` 作为视觉基准。它的根卡片：
```
className="bg-card border border-border rounded-xl px-8 py-6 shadow-[var(--shadow-card)] flex flex-col items-center gap-5 mx-auto w-full max-w-[1320px]"
data-design-id="pdf:card"
```
标题：`<div data-design-id="pdf:title" className="text-lg text-foreground font-semibold">📄 PDF 解析中心</div>`
section：`<section className="flex flex-col items-center gap-2.5 w-full">`
section 小标题：`className="text-sm text-muted-foreground font-semibold"`

## 改造规则

### 1. 根卡片居中
把页面最外层内容包进居中卡片（或改造现有根 div 的 className）：
`bg-card border border-border rounded-xl px-8 py-6 shadow-[var(--shadow-card)] flex flex-col gap-5 mx-auto w-full max-w-[1320px]`
加 `data-design-id="<ROUTE>:card"`。然后按页面类型决定是否加 `items-center`：
- **纵向表单/列表页**（单列，像 PDF）：加 `items-center`；内部 section 用 `flex flex-col items-center gap-2.5 w-full`。
- **横向两栏页**（左列表+右详情 并排 grid/flex-row）：**不要**加 `items-center`，只加 `mx-auto w-full max-w-[1320px]`，两栏内部保持原样。
- **网格页**（dashboard 统计卡片网格）：根加 `mx-auto max-w-[1320px]`，网格本身不要 items-center（网格自己撑满即可）。

### 2. 标题
页面顶部标题统一为 `text-lg text-foreground font-semibold`，加 `data-design-id="<ROUTE>:title"`。没有标题的页面，在卡片内首行加一个（用该页的语义标题，如「🧠 记忆管理」「📁 数据文件管理」）。

### 3. data-design-id 打标
给这些**静态**元素加 `data-design-id="<ROUTE>:<name>"`：根 card、title、主操作按钮(`btn-<name>`)、主输入框(`input-<name>`)、主下拉(`select-<name>`)、tab 组容器与各 tab(`tab-<name>`)、按钮行容器(`row-<name>`)、区块小标题(`label-<name>`)。
- **不要**给 `.map` 动态列表项打标（id 不稳定）。
- **不要**给 `fixed inset-0` 全屏遮罩层打标（会挡全屏）。弹窗**内部**内容卡片可打标。
命名前缀按路由：dashboard / report / memory / files / history / generate / settings / workflows / kb / task。

### 4. 按钮（铁律：横向 px ≥ 2 × 纵向 py）
统一主操作按钮到（注意 py-2 px-8 满足 8≥2×2=4）：
```
inline-flex items-center justify-center gap-3 min-h-[40px] py-2 px-8 bg-primary text-primary-foreground rounded-lg text-sm cursor-pointer transition-opacity hover:opacity-90 disabled:opacity-50 disabled:cursor-not-allowed shrink-0
```
次按钮(ghost)：把 `bg-primary text-primary-foreground` 换成 `bg-primary/10 text-primary border border-primary/20`、`transition-colors hover:bg-primary/20`。
危险按钮：`... min-h-[36px] py-1.5 px-6 bg-error/10 text-error border border-error/20 rounded-md ... transition-colors hover:bg-error/15`。
仅图标的方形小按钮可保留较小尺寸，但确保 px ≥ 2×py。
**保留所有 disabled / cn() 条件逻辑**——只替换基础 class 串，条件分支原样保留。

### 5. 输入框/下拉
input：`h-10 px-5 bg-muted border border-border rounded-lg text-foreground text-sm outline-none focus:border-primary focus:ring-2 focus:ring-primary/20 placeholder:text-muted-foreground`
select：`h-10 px-5 bg-muted border border-border rounded-lg text-foreground text-sm text-center outline-none focus:border-primary`
已是类似样式的可不动；明显不一致的（如 `py-2 px-4` / `rounded-md` 混用）统一成上面这套。select 选项 `<option>` 可加 `text-center`。

## 严格保留（违反=失败）
- 所有 useState/useEffect/useCallback、props、event handler、fetch 调用、条件渲染、ref、disabled 逻辑——**一字不改**。
- 只改 className 字符串、必要时加包裹 div、加 data-design-id 属性。
- 不改 import（除非包裹结构需要，一般不需要）。不改组件签名 / props 类型。
- 不改 framer-motion 的 variants / initial / animate 结构（可给 motion.div 加 data-design-id）。
- 动态 `.map` 渲染的项不加 data-design-id。
- Tailwind v4：可用任意值 `w-[NNNpx]` / `min-h-[NNpx]` 等。

## 禁止
- **不要**运行 build / dev / tsc / 任何服务启动或重启命令。只改文件。
- **不要**改 `frontend/.design-overrides.json`、`TopBar.tsx`、`Sidebar.tsx`、`DetailPanel.tsx`、`client-layout.tsx`、`globals.css`、`lib/design-mode/*`。
