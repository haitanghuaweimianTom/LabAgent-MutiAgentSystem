# acm_sigconf References

> 基于 arxiv 真实条目的 ACM SIG 会议接收论文（SIGMOD / CHI / CSCW / SIGMETRICS）。所有条目均通过 https://arxiv.org/abs/<id> 验证 comments / journal-ref 字段。

## ACM SIGMOD 2024

- **arXiv:2401.02116** — *Starling: An I/O-Efficient Disk-Resident Graph Index Framework for High-Dimensional Vector Similarity Search on Data Segment* — Wang M., Xu W., Yi X., Wu S., Peng Z., Ke X., Gao Y., Xu X., Guo R., Xie C. — **ACM SIGMOD 2024**
  - 一句话：I/O-efficient 磁盘驻留图索引框架，2GB 内存下容纳 33M 128-dim 向量、查询延迟 < 1ms、吞吐量较 SOTA 高 43.9×。
  - 验证：arxiv comments "This paper has been accepted by SIGMOD 2024"
  - URL: https://arxiv.org/abs/2401.02116

- **arXiv:2401.03359** — *In-Database Data Imputation* — Perini M., Nikolic M. — **ACM SIGMOD 2024**
  - 一句话：在 PostgreSQL 和 DuckDB 内做 MICE 数据填补，通过 ring abstraction + computation sharing 比其他 MICE 实现快 2 数量级。
  - 验证：arxiv comments "Published at SIGMOD 2024 (26 pages)"
  - URL: https://arxiv.org/abs/2401.03359

## ACM SIGMETRICS 2024

- **arXiv:2401.01168** — *FedQV: Leveraging Quadratic Voting in Federated Learning* — Chu T., Laoutaris N. — **ACM SIGMETRICS 2024**
  - 一句话：基于 quadratic voting 的 FL aggregation 算法，提供 truthful mechanism 保证 + 与 SoTA 匹配的收敛率，且抗 poisoning 攻击。
  - 验证：arxiv comments "Please cite the ACM SIGMETRICS'24 version of this paper"
  - URL: https://arxiv.org/abs/2401.01168

## ACM CSCW 2024
