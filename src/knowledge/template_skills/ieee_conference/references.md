# ieee_conference References

> 基于 arxiv 真实条目的 IEEE 会议接收论文（CVPR / ICASSP / INFOCOM）。所有条目均通过 https://arxiv.org/abs/<id> 验证 comments / journal-ref 字段。

## IEEE CVPR 2024

- **arXiv:2401.00029** — *6D-Diff: A Keypoint Diffusion Framework for 6D Object Pose Estimation* — Xu L., Qu H., Cai Y., Liu J. — **CVPR 2024 Camera-Ready**
  - 一句话：基于 Mixture-of-Cauchy 扩散过程的 6D 物体姿态估计，将 2D 关键点检测建模为 reverse diffusion 过程。
  - 验证：arxiv comments "CVPR 2024 CAMERA-READY"
  - URL: https://arxiv.org/abs/2401.00029

- **arXiv:2401.00094** — *Generating Enhanced Negatives for Training Language-Based Object Detectors* — Zhao S., Zhao L., B.G V., Suh Y., Metaxas D., Chandraker M., Schulter S. — **CVPR 2024**
  - 一句话：用 LLM 生成 negative text descriptions + text-to-image diffusion 生成 negative images，提升 open-vocabulary detector 性能。
  - 验证：arxiv comments "Accepted to CVPR 2024. The supplementary document included"
  - URL: https://arxiv.org/abs/2401.00094

- **arXiv:2401.00374** — *EMAGE: Towards Unified Holistic Co-Speech Gesture Generation via Expressive Masked Audio Gesture Modeling* — Liu H., Zhu Z., Becherini G., Peng Y., Su M., Zhou Y., Zhe X., Iwamoto N., Zheng B., Black M. — — **CVPR 2024**
  - 一句话：BEAT2 (BEAT-SMPLX-FLAME) 数据集 + Masked Audio Gesture Transformer + 4 个 compositional VQ-VAEs 做 holistic 共语音手势生成。
  - 验证：arxiv comments "Fix typos; Conflict of Interest Disclosure; CVPR Camera Ready"
  - URL: https://arxiv.org/abs/2401.00374

## IEEE ICASSP 2024

- **arXiv:2401.00155** — *A comprehensive framework for occluded human pose estimation* — Xu L., Zhao L., Sun X., Wang D., Li G., Yan K. — **ICASSP 2024**
  - 一句话：DAG (Data, Attention, Graph) 框架处理遮挡人体姿态估计，含 mask joints 数据增广 + ADAM + FGMP-GCN。
  - 验证：arxiv comments "Accepted to ICASSP 2024"
  - URL: https://arxiv.org/abs/2401.00155

## IEEE INFOCOM 2024

- **arXiv:2401.03812** — *ORANUS: Latency-tailored Orchestration via Stochastic Network Calculus in 6G O-RAN* — Adamuz-Hinojosa O., Zanzi L., Sciancalepore V., Garcia-Saavedra A., Costa-Pérez X. — **IEEE INFOCOM 2024**
  - 一句话：用 stochastic network calculus 在 6G O-RAN 中做 latency-tailored slicing orchestration。
  - 验证：arxiv comments "Accepted for publication in IEEE INFOCOM 2024"
  - URL: https://arxiv.org/abs/2401.03812

- **arXiv:2401.04996** — *Distributed Experimental Design Networks* — Li Y., Su L., Joe-Wong C., Yeh E., Ioannidis S. — **IEEE INFOCOM 2024**
  - 一句话：把 networked 实验设计 + bandit 推理结合，做分布式 A/B testing 资源分配。
  - 验证：arxiv comments "Technical report for paper accepted by INFOCOM 2024"
  - URL: https://arxiv.org/abs/2401.04996
