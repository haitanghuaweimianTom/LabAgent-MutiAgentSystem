# aaai_2024 References

> 基于 arxiv 真实条目的 AAAI 2024 接收论文。所有条目均通过 https://arxiv.org/abs/<id> 验证 comments / journal-ref 字段。

## AAAI 2024 主会议

- **arXiv:2401.00298** — *Principal-Agent Reward Shaping in MDPs* — Ben-Porat O., Mansour Y., Moshkovitz M., Taitler B. — **AAAI 2024**
  - 一句话：在 principal-agent Stackelberg game 中研究 budget-constrained reward shaping，证明 NP-hardness + 给 stochastic tree / deterministic DP 的多项式近似算法。
  - 验证：arxiv comments "Full version of a paper accepted to AAAI'24"
  - URL: https://arxiv.org/abs/2401.00298

- **arXiv:2401.00315** — *Bidirectional Temporal Plan Graph: Enabling Switchable Passing Orders for More Efficient Multi-Agent Path Finding Plan Execution* — Su Y., Veerapaneni R., Li J. — **AAAI 2024**
  - 一句话：BTPG 在 MAPF plan execution 中允许 switching passing orders，比 TPG 减少 8-20% 不必要等待时间。
  - 验证：arxiv comments "Accepted by AAAI-2024"
  - URL: https://arxiv.org/abs/2401.00315

- **arXiv:2401.03194** — *Learning Persistent Community Structures in Dynamic Networks via Topological Data Analysis* — Kong D., Zhang A., Li Y. — **AAAI 2024**
  - 一句话：MFC (matrix factorization-based deep graph clustering) + TopoReg (topological similarity regularization) 做 dynamic community detection 的 temporal consistency。
  - 验证：arxiv comments "AAAI 2024"
  - URL: https://arxiv.org/abs/2401.03194

- **arXiv:2401.00268** — *COMMA: Co-Articulated Multi-Modal Learning* — Hu L., Gao L., Liu Z., Pun C., Feng W. — **AAAI 2024**
  - 一句话：Co-Articulated vision-language prompt learning，通过 prompt 互相注入 + 知识保持缓解 CLIP 微调中的灾难性遗忘。
  - 验证：arxiv comments "Accepted to AAAI2024. Code is available at https://github.com/hulianyuyy/COMMA"
  - URL: https://arxiv.org/abs/2401.00268

- **arXiv:2401.01377** — *Does Few-shot Learning Suffer from Backdoor Attacks?* — Liu X., Jia X., Gu J., Xun Y., Liang S., Cao X. — **AAAI 2024**
  - 一句话：揭示并系统研究 few-shot learning 中的 backdoor attack 漏洞（cs.CR + cs.AI 跨方向）。
  - 验证：arxiv comments "AAAI2024"
  - URL: https://arxiv.org/abs/2401.01377
